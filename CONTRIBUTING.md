# Участие в проекте

Сообщения об ошибках, улучшения документации и pull request приветствуются.

Перед изменениями прочитайте [описание разработки](docs/DEVELOPMENT.md). Для ошибки укажите версию, систему, масштаб экрана и шаги воспроизведения. Для изменения кода кратко опишите проблему, новое поведение и способ проверки.

Перед pull request выполните:

```sh
npm test
npm run check
npm run test:ui
```

Изменения интерфейса сопровождайте актуальными скриншотами через `npm run screenshots`. Используйте демонстрационные данные. Не добавляйте в репозиторий личные расписания, аудиофайлы пользователей, секреты, `node_modules` и готовые установщики.

Сохраняйте разделение main / preload / renderer и совместимость пользовательского файла `schedule-v2.json`. Изменение формата требует миграции. Изменение размера окна проверяйте и после запуска в полном виде, и после запуска в компактном.

Присланные изменения распространяются по лицензии MIT проекта.
