# История изменений

## 2.1.0

- Проект подготовлен для публичного репозитория: исходники, ресурсы, документация и тесты разнесены по папкам.
- Добавлены руководство пользователя, инструкции для разработчика, публикации и выпуска релиза.
- Добавлены реальные скриншоты интерфейса и воспроизводимый скрипт их получения.
- Настроены установщик Windows NSIS, DMG/ZIP для Mac и GitHub Actions для сборки.
- Добавлены UI-проверки, шаблон сообщения об ошибке, MIT LICENSE и контрольные суммы релизов.
- Логика расписания и исправления версий 2.0.1–2.0.2 сохранены.
- Исправлена замена выделенных часов по одной цифре без потери минут.

## 2.0.2

- Исправлено уменьшение самого окна при переходе из обычного режима в компактный на Windows.
- Добавлены проверки многократного переключения размеров.

## 2.0.1

- В полях времени разрешены только цифры.
- Двоеточие вставляется автоматически; исправлены вставка текста и работа каретки.

## 2.0.0

- Добавлены стартовое меню, недельное расписание и редактор занятий.
- Добавлены настраиваемые звуки, копирование дней, экспорт и импорт.
- Подготовлена версия для macOS Apple Silicon.

## 1.1

- Добавлены сигналы начала и окончания занятий.

## 1.0

- Первая версия для Windows: фиксированное расписание, обратный отсчёт уроков и перемен, окно поверх приложений.
