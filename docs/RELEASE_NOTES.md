## LessonTimer 2.1.0

Недельный редактор расписания и плавающий таймер уроков для Windows и macOS.

### Возможности

- Расписание отдельно для каждого дня недели и автоматические перемены.
- Окно поверх приложений, компактный вид и настройка непрозрачности.
- Три встроенных звонка, свой WAV/MP3/OGG и регулировка громкости.
- Ввод времени только цифрами с автоматическим двоеточием.
- Копирование дней, проверка пересечений, экспорт и импорт со звуком.

Включено исправление уменьшения окна при переключении в компактный режим Windows.

### Что скачать

- Windows x64: `.exe` для установки или `.zip` для переносного запуска.
- Mac M1 и новее: файл с `mac-arm64` в названии.
- Mac Intel: файл с `mac-x64` в названии.

Нужны Windows 10/11 x64 или macOS 13+. Node.js и Python не требуются. Подробная инструкция находится в `docs/USER_GUIDE.md` репозитория.

Сборки не имеют доверенной подписи издателя Windows / нотариальной проверки Apple, поэтому возможны системные предупреждения при первом запуске. Пользовательские данные хранятся отдельно и сохраняются при обновлении. Перед обновлением можно сделать экспорт расписания.
