## LessonTimer 2.2.0

- Светлая, тёмная и системная темы в меню и плавающем таймере.
- Любой акцентный цвет: системная палитра, HEX и готовые варианты.
- Мини-режим 270×84: убрано лишнее место под таймером.
- Улучшено отображение поверх приложений, рабочих столов и полноэкранных окон macOS.
- Проверка новых релизов при запуске и вручную во вкладке «Обновления».
- Загрузка с прогрессом, проверка SHA-256 и установка с перезапуском после согласия. На Mac предусмотрен откат, если новая версия не запустилась.

Расписание, настройки и свой звонок сохраняются. Проверку обновлений при запуске можно отключить.

**С 2.1.0 и старее нужно один раз обновиться вручную до этой версии.** Автообновление появится после установки 2.2.0.

### Что скачать

- Windows x64: `.exe` — установка и последующие автообновления; `.zip` — переносная сборка с ручным обновлением.
- Mac M1 и новее: `mac-arm64.dmg`; Intel: `mac-x64.dmg`. Перенесите приложение в «Программы»; для автообновления нужна запись в папку установки.

Нужны Windows 10/11 x64 или macOS 13+. Node.js и Python не требуются.

Сборки пока без доверенной подписи издателя Windows и нотариальной проверки Apple. При первом запуске возможны системные предупреждения. Инструкция: [руководство пользователя](https://github.com/egorca05/LessonTimer/blob/main/docs/USER_GUIDE.md).
